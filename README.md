# VoltRelay Energy Analytics

## Project Overview
This project analyzes the performance of the VoltRelay EV battery-swapping network using 3.87 million swap attempts across 152 stations.

## Key Findings

- Total swap attempts: 3,877,013
- Completed swaps: 3,645,809
- Overall success rate: 94.04%
- Overall failure rate: 5.96%
- Total revenue: ₹233.13 million
- Average queue wait: 242.95 seconds
- Average battery SOH: 88.17%

## Analysis Areas

- Network performance
- Monthly performance
- City-wise performance
- Station failure analysis
- Charger generation performance
- Battery SOH analysis
- Battery supplier performance
- Tariff and revenue analysis
- Rider retention analysis

## Important Observations

Gen1 chargers recorded a 7.23% failure rate compared with 4.84% for Gen2 and Gen3.

Batteries with SOH below 70% had a 10.28% failure rate, compared with 4.65% for batteries in the 80–90% SOH range.

The analysis also identified stations with comparatively higher failure rates and examined differences across cities, tariffs and rider retention.
